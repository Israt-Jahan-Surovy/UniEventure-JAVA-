UniEventure

UniEventure is a comprehensive event management system designed for universities. It allows event organizers and students to manage and participate in university events seamlessly. The system includes functionalities for signing up, logging in, booking events, and participating in them, along with an admin portal for managing users and events.

Features

•	Homepage:

  o	Sign up or log in to your account.
	
  o	View available events directly from the homepage.

•	User Registration:

  o	University event organizers and students can sign up with accurate information.
	
  o	Validation ensures the correctness of data during the sign-up process.

•	UserDashboard:

  o	A common dashboard for all users.
	
  o	Navigate to:
	
  	OrganizerDashboard: Book events as an organizer.
	
  	ParticipantDashboard: Participate in events by filling out an information form.

•	Admin Portal:

   o	Admins can log in by checking the admin data file for credentials.
	 
   o	Manage all user and event information efficiently.

How It Works

1.	Sign Up:
   
    o	University event organizers and students must register using valid information.
  	
    o	Validation ensures correct and complete data.

3.	Login:
   
    o	Access your account by providing the correct credentials.
  	
    o	Organizers and students share a common UserDashboard upon login.

5.	OrganizerDashboard:
   
    o	Book an event by selecting available venues, dates, and time slots.
  	
    o	Add details about the event to ensure proper scheduling.

7.	ParticipantDashboard:
   
    o	View a list of available events.
  	
    o	Participate in events by completing a simple information form.

9.	Admin Portal:
   
    o	Admins can log in using credentials from the admin data file.
  	  
    o	Manage all user accounts and events effectively, including adding or removing records as needed.

Prerequisites

To run UniEventure, you will need:

•	Java 8 or later.

•	A Java-compatible IDE (like IntelliJ IDEA or Eclipse).

•	Access to text files for managing user, event, and admin data.

Installation and Execution
1.	Download the repository as a ZIP file from GitHub.
2.	Extract the ZIP file to your desired location.
3.	Open a terminal or command prompt and navigate to the extracted folder.
4.	Compile the program: javac Start.java java Start
